# BPE Tokenizer - Домашнее задание 3

Реализация BPE (Byte Pair Encoding) токенизатора с претокенизацией и специальными токенами.

## Описание

Проект включает:
- **BPE токенизатор** с претокенизацией (паттерны основаны на GPT-2 стиле)
- Скрипты для обучения токенизатора
- Скрипты для анализа эффективности токенизации
- Анализ зависимости compression ratio от размера словаря
- Анализ неиспользованных токенов

## Установка

```bash
pip install -r requirements.txt
```

## Структура проекта

- `bpe_tokenizer.py` - Основной класс BPE токенизатора
- `train_tokenizer.py` - Скрипт для обучения токенизатора
- `analyze_tokenizer.py` - Скрипт для анализа эффективности
- `vocab_size_analysis.py` - Анализ зависимости от размера словаря
- `unused_tokens_analysis.py` - Анализ неиспользованных токенов
- `run_all_analysis.py` - Скрипт для выполнения всех анализов

## Быстрый старт

### Важно: Использование реальных корпусов

Для качественных результатов рекомендуется использовать реальные корпуса текстов, а не примерные данные.

1. **Подготовка корпусов** (если у вас есть исходные файлы):
```bash
# Объединить несколько файлов в один корпус
python prepare_corpus.py --input-dir data/raw --output corpus.txt

# Разделить на обучающий и тестовый корпусы
python prepare_corpus.py --input-dir data/raw --output corpus.txt --split
```

2. **Или создайте примерные данные** (только для тестирования):
```bash
python create_sample_data.py
```

3. Выполните все анализы:
```bash
python run_all_analysis.py --train train_corpus.txt --test test_corpus.txt --pushkin pushkin_corpus.txt
```

## Использование

### 1. Обучение токенизатора

```bash
python train_tokenizer.py --input train_corpus.txt --output tokenizer.json --vocab-size 10000
```

### 2. Анализ эффективности токенизации

```bash
python analyze_tokenizer.py --tokenizer tokenizer.json --texts test_corpus.txt --domains "Тестовый домен"
```

Для сравнения нескольких доменов:
```bash
python analyze_tokenizer.py --tokenizer tokenizer.json --texts domain1.txt domain2.txt domain3.txt --domains "Домен1" "Домен2" "Домен3"
```

### 3. Анализ зависимости compression ratio от размера словаря

```bash
python vocab_size_analysis.py --train train_corpus.txt --test test_corpus.txt --output vocab_analysis.json
```

### 4. Анализ неиспользованных токенов

```bash
python unused_tokens_analysis.py --tokenizer tokenizer.json --texts pushkin_corpus.txt --output unused_tokens.txt
```

### 5. Полный анализ (все задачи)

```bash
python run_all_analysis.py --train train_corpus.txt --test test_corpus.txt --pushkin pushkin_corpus.txt
```

## Особенности реализации

### Претокенизация

Используется паттерн претокенизации, основанный на GPT-2 подходе:
- Разбиение текста на слова, числа, пунктуацию и пробелы
- **Правильная обработка русских букв (кириллицы)**: использует `isalpha()` для всех Unicode букв
- Поддержка всех русских букв, включая ё, Ё и другие
- Адаптация для русского языка

### Специальные токены

- `<unk>` - неизвестный токен
- `<pad>` - токен заполнения
- `<bos>` - начало последовательности
- `<eos>` - конец последовательности

### BPE алгоритм

1. Инициализация словаря байтами и специальными токенами
2. Преобразование слов в последовательности байтов (через unicode mapping)
3. Итеративное слияние наиболее частых пар символов
4. Построение словаря заданного размера

## Формат данных

Текстовые файлы должны быть в кодировке UTF-8. Тексты разделяются двойными переносами строк (`\n\n`).

## Результаты анализа

### Коэффициент сжатия
- **Токены / Байты**: отношение количества токенов к количеству байт
- **Токены / Символы**: отношение количества токенов к количеству символов

### Токены на слово
- Среднее количество токенов на слово (общее)
- Среднее количество токенов на слово для топ 10% частотных слов

### Сравнение доменов
Анализ показывает, отличается ли эффективность токенизации для разных доменов текста.
